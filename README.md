# Eric Gonzalez-Payne
### School leader, educator and software builder

I'm an educator and school founder with an Ed.M. from Harvard. My work starts with the people a school serves: students, families and the team supporting them.

Supporting that team means building useful systems. Alongside choosing and using existing software, I build tools for teaching, school operations and learning through play. I bring classroom experience and educational product design to practical software development.

I have released source code for **12 projects on GitHub**, from standalone tools to early previews. I share selected work so other people can use it, adapt it and build on it. This count reflects the projects below as of 6 November 2026; it excludes the profile repository, placeholder repositories and private versions of the same projects.

## Teaching and school tools

- **[InquiryForge Teacher Studio](https://github.com/Empathyglobal/inquiryforge)** helps teachers plan inquiry-based history, social studies and science projects, including topic choices, assignment briefs, timelines and rubrics. It runs in a browser without an account, API key or build process. Topic matching uses a built-in bank and transparent rules.
- **[School Library Catalogue](https://github.com/Empathyglobal/school-library-catalogue)** provides search and filtering for 1,026 factual book records from a historical school catalogue snapshot. It runs on a static server without an account or application backend. Borrower records and book covers are excluded; recorded copy counts are historical, not live availability.
- **[Create](https://github.com/Empathyglobal/create)** is a teacher-supervised creative workspace for stories, questions and interactive projects. The public source preview includes Story, Chat and Code workflows, with live generation and account connections disabled. It is not a finished classroom deployment.
- **[Alpha Project Finder / Project Path](https://github.com/Empathyglobal/alpha-project-finder)** is a prototype for choosing portfolio projects and planning milestones. The source includes rule-based matching, shortlists and mentor workflows. The default build is an offline setup screen, not a live student service.

## Games and learning simulations

- **[Unlikely Empires](https://github.com/Empathyglobal/unlikely-empires)** is a browser strategy game about building cities, managing unrest and guiding ten peoples through six eras. The source release includes solo play, local saves and multiplayer support. [Play on the website](https://www.unlikelyempires.com/); the hosted game may differ from the source release.
- **[Raising Tomorrow](https://github.com/Empathyglobal/raising-tomorrow-community-preview)** explores parenting choices, consequences, repair and learning. The community preview runs locally with built-in scenarios and browser saves. Online services, remote AI and payments are excluded.
- **[GameTheory](https://github.com/Empathyglobal/gametheory-community-preview)** contains seven social-strategy simulations about cooperation, trust, negotiation and shared resources. The other participants are rule-driven computer characters, not people online or a live AI service. The standalone preview needs no account or backend; automated model checks pass, while full browser testing remains pending.

## Communication and reflection

- **[Empathetic Words](https://github.com/Empathyglobal/empathetic-words)** is a communication-skills practice game with 37 fictional stories. Players build responses through observation, feeling, need and request, with optional on-device narration. No account or backend is needed, and progress resets on reload. Automated checks and desktop/mobile-emulated Chromium smoke tests pass; actual device audio and broader accessibility testing remain pending.
- **[The Empathy Measure](https://github.com/Empathyglobal/empathy-measure)** is an experimental conversation and reflection app exploring seven emotional skills. Its backend-free preview includes fictional reports, with live inference disabled. It is not a validated psychological test and should not be used for consequential decisions about people.
- **[BridgeConnect](https://github.com/Empathyglobal/bridgeconnect)** is a family conversation and supervised-learning workspace with parent review and activity summaries. This community alpha requires its own backend configuration and privacy/security review before use with real family information.

## Administrative tools

- **[Charity Hospital Reporting](https://github.com/Empathyglobal/charity-hospital-reporting)** is experimental administrative reporting software for organizing source material, tracing claims to evidence and exporting human-reviewed drafts. Its local preview uses example records; optional server-side AI is disabled by default. It is not an electronic health record or a clinically validated system.
- **[Charity Hospital Accounting](https://github.com/Empathyglobal/charity-hospital-accounting)** is an early local-first toolkit with reusable calculation modules and a pharmacy PDF-to-CSV review screen. It is not a complete accounting system, ledger, medication-management tool or financial approval system.
