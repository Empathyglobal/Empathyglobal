# Eric Gonzalez-Payne
### Educator, school founder and software builder

I'm an educator and school founder with an Ed.M. from Harvard. I care about making the world a better place through education and practical tools that help people and organizations.

I build and test software for organizations, then choose selected projects to release publicly so others can use them, adapt them and build businesses of their own. I enjoy seeing useful ideas grow beyond their original purpose.

My work brings together classroom practice, educational product design, interactive simulations and practical software development.

## Explore my public projects

### Teaching and learning

- **[InquiryForge Teacher Studio](https://github.com/Empathyglobal/inquiryforge)**: Plan inquiry-based history, social studies and science projects, with topic choices, assignment briefs, timelines and rubrics. Runs in a browser without an account, API key or build process.
- **[Create](https://github.com/Empathyglobal/create)**: A teacher-supervised creative workspace for stories, questions and interactive projects. The public source preview includes Story, Chat and Code workflows; live generation and account connections are disabled.
- **[Alpha Project Finder](https://github.com/Empathyglobal/alpha-project-finder)**: A prototype for matching students with portfolio projects and planning milestones. The source includes rule-based matching, shortlists and mentor workflows; the default build is an offline setup screen, not a live student service.

### Games and simulations

- **[Unlikely Empires](https://github.com/Empathyglobal/unlikely-empires)**: A browser strategy game about building cities, managing unrest and guiding ten peoples through six eras. Includes solo play, local saves and multiplayer support. [Play on the website](https://www.unlikelyempires.com/).
- **[Raising Tomorrow](https://github.com/Empathyglobal/raising-tomorrow-community-preview)**: A parenting life simulation about choices, consequences, repair and learning. The community preview runs locally, with built-in scenarios and browser saves; online services are excluded.

- **[GameTheory](https://github.com/Empathyglobal/gametheory-community-preview)**: Seven social-strategy simulations about cooperation, trust, negotiation and shared resources. Rule-driven computer characters create a social-game experience without live multiplayer, accounts or a backend. This community source preview has automated model checks; full browser testing remains pending.

### Reflection and family tools

- **[The Empathy Measure](https://github.com/Empathyglobal/empathy-measure)**: An experimental conversation and reflection app exploring seven emotional skills. The public preview uses fictional reports and has live inference disabled. It is not a validated psychological test.
- **[BridgeConnect](https://github.com/Empathyglobal/bridgeconnect)**: A family conversation and supervised-learning workspace with parent review and activity summaries. This community alpha requires its own backend configuration and review before use with real family information.

See each repository for setup, release status and known limitations. Development records are included where available. Hosted products, including the Unlikely Empires play site, may differ from their public source releases.
